# Template Skrip Video Pendek

Gunakan struktur ini untuk setiap video (durasi total target 15-45 detik).

```
Judul internal   : [pilar] / [format] / eps [nomor]
Narator (suara)  : [Pak Bahri | Kak Nur | Adit]
Kategori footage : [Kebun dataran tinggi | Rumah giling & roastery | Warung kopi & brewing]
Durasi target    : [xx] detik

HOOK (0-3 detik)
  Footage : [shot B-roll yang menarik perhatian, lihat shot-list-footage-template.md]
  Narasi  : "[kalimat pembuka - pertanyaan/klaim mengejutkan/fakta ringkas]"

ISI (beat 1)
  Footage : [...]
  Narasi  : "[...]"
  Overlay : [grafis/data pendukung kalau ada, mis. peta kecil/angka]

ISI (beat 2)
  Footage : [...]
  Narasi  : "[...]"

CTA (3-5 detik terakhir)
  Footage : [shot penutup, mis. cupping/menuang kopi]
  Narasi  : "[ajakan follow/like/komentar, atau lempar pertanyaan ke penonton]"

Caption on-screen : [ringkasan 1 baris untuk teks yang di-burn-in, harus terbaca tanpa suara]
```

## Contoh (format `mitos_vs_fakta`, pilar `mitos_fakta`, narator Kak Nur)

```
HOOK
  Footage : B-roll cupping table di roastery, cangkir kopi diaduk.
  Narasi  : "Semua kopi Sumatra itu kopi luwak? Big NO."

ISI (beat 1)
  Footage : Peta kecil animasi Gayo-Lintong-Mandailing (overlay grafis, bukan bagian dari klip B-roll).
  Narasi  : "99% kopi Sumatra yang kamu minum itu diproses manusia lewat giling basah, bukan dari luwak."
  Overlay : Peta lokasi + label "giling basah" sebagai nilai tambah edukatif (bukan cuma footage polos).

ISI (beat 2)
  Footage : B-roll proses giling basah di rumah giling (mesin huller, biji basah).
  Narasi  : "Proses giling basah inilah yang bikin rasanya earthy dan body-nya tebal, bukan karena luwak."

CTA
  Footage : Close-up biji hijau kebiruan khas Sumatra.
  Narasi  : "Follow biar kamu nggak salah kaprah soal kopi lagi!"

Caption on-screen : "Kopi Sumatra ≠ Kopi Luwak. Ini faktanya 👇"
```

Overlay grafis/data bukan sekadar hiasan — ini yang membedakan video dari "footage + caption biasa"
dan membantu lolos kebijakan reused-content YouTube (lihat `references/platform-guidelines.md`).
