# Template Metadata Upload (TikTok Studio & YouTube Shorts)

```
Episode         : Eps [n]/100 — [tanggal]
Pilar           : [id pilar]
Format          : [id format]

--- TikTok ---
Caption         : [hook singkat, max ~150 karakter] Eps [n]/100 🌱☕
Hashtag         : #kopisumatra #[pilar terkait] #edukasikopi #coffeetok [1-2 hashtag spesifik lain]
Label konten AI : ON hanya kalau voiceover TTS terdengar sangat realistis, OFF kalau tidak berlaku
Jadwal upload   : [HH:MM WIB]

--- YouTube Shorts ---
Judul           : [Judul mengandung keyword, <100 karakter] #Shorts
Deskripsi       : [1-2 kalimat ringkasan] | Eps [n]/100 seri Kopi Sumatra: Dari Kebun ke Cangkir.
                  #kopisumatra #edukasikopi #Shorts
Label AI        : lihat catatan TikTok di atas — sama untuk YouTube
Sumber footage  : [catat sumber/lisensi tiap klip yang dipakai, lihat shot-list-footage-template.md]
Jadwal upload   : [HH:MM WIB]
```

## Contoh Terisi

```
Episode         : Eps 12/100 — 2026-08-07
Pilar           : giling_basah
Format          : mitos_vs_fakta

--- TikTok ---
Caption         : Kenapa biji kopi Sumatra warnanya kebiruan? Ternyata ini sebabnya 👀 Eps 12/100 🌱☕
Hashtag         : #kopisumatra #kopigilingbasah #edukasikopi #coffeetok #baristatips
Label konten AI : OFF (footage nyata, voiceover TTS standar)
Jadwal upload   : 09:15 WIB

--- YouTube Shorts ---
Judul           : Rahasia Biji Kopi Sumatra Berwarna Kebiruan #Shorts
Deskripsi       : Proses giling basah bikin biji kopi Sumatra beda dari kopi manapun di dunia.
                  Eps 12/100 seri Kopi Sumatra: Dari Kebun ke Cangkir. #kopisumatra #edukasikopi #Shorts

```

Catatan: sebar 100 slot jadwal sepanjang hari (lihat `references/platform-guidelines.md`), jangan
upload serentak.
