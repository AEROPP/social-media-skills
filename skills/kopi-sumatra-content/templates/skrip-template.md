# Template Skrip Video Pendek

Gunakan struktur ini untuk setiap video (durasi total target 15-45 detik).

```
Judul internal   : [pilar] / [format] / eps [nomor]
Host             : [Pak Bahri | Kak Nur | Adit]
Setting          : [Kebun Gayo | Kebun Lintong | Rumah Giling Mandailing]
Durasi target    : [xx] detik

HOOK (0-3 detik)
  Visual : [aksi/ekspresi pembuka yang menarik perhatian]
  Narasi : "[kalimat pembuka - pertanyaan/klaim mengejutkan/fakta ringkas]"

ISI (beat 1)
  Visual : [...]
  Narasi : "[...]"

ISI (beat 2)
  Visual : [...]
  Narasi : "[...]"

ISI (beat 3, opsional untuk format >20 detik)
  Visual : [...]
  Narasi : "[...]"

CTA (3-5 detik terakhir)
  Visual : [host menatap kamera / gesture ajakan]
  Narasi : "[ajakan follow/like/komentar, atau lempar pertanyaan ke penonton]"

Caption on-screen : [ringkasan 1 baris untuk teks yang di-burn-in, harus terbaca tanpa suara]
```

## Contoh (format `mitos_vs_fakta`, pilar `mitos_fakta`, host Kak Nur)

```
HOOK
  Visual : Kak Nur mengangkat cangkir cupping dengan ekspresi geli, latar roastery.
  Narasi : "Semua kopi Sumatra itu kopi luwak? Big NO."

ISI (beat 1)
  Visual : Kak Nur menunjuk peta kecil animasi Gayo-Lintong-Mandailing.
  Narasi : "99% kopi Sumatra yang kamu minum itu diproses manusia lewat giling basah, bukan dari luwak."

ISI (beat 2)
  Visual : Cut ke proses giling basah di rumah giling.
  Narasi : "Proses giling basah inilah yang bikin rasanya earthy dan body-nya tebal, bukan karena luwak."

CTA
  Visual : Kak Nur nyengir ke kamera.
  Narasi : "Follow biar kamu nggak salah kaprah soal kopi lagi!"

Caption on-screen : "Kopi Sumatra ≠ Kopi Luwak. Ini faktanya 👇"
```
